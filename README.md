The Golden Ladle is a fast, original 2D cooking game: run a tiny bistro through the lunch rush — read tickets off the order board, chop veg on the board, grill patties before they burn, stack each dish on a plate and ring the serving bell before customers walk out. Four original recipes, tips for fast serves, combos, and a 150-second shift that gets busier as it goes.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click to walk and use stations, or steer with WASD / arrow keys and press E to use the nearest station. P pauses, M mutes.
